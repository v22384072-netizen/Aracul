Карты Знают — Telegram Mini App
Проект мини-приложения для колоды «Карты Знают» из 60 карт.
Что загружено
`index.html` — интерфейс приложения
`styles.css` — тёмный мистический дизайн
`app.js` — 60 карт (единый объект на карту: title/category/meaning/shadow/question/direction/img), каталог, вытягивание карты, расклады 1/3/5 и локальная история
`cards/` — картинки карт (см. ниже)
Картинки карт
Кладите файлы в папку `cards/` с именем по номеру карты, с ведущим нулём:
```
cards/01.png   — Фундамент
cards/02.png   — Золотая жила
...
cards/60.png   — Золотой ребёнок
```
Порядок карт и их номера — в массиве `cards` внутри `app.js`. Если для какого-то номера файла ещё нет — приложение не ломается, просто показывает символ ✦ вместо картинки. Так можно добавлять картинки постепенно, без правок кода.
Как проверить локально
Нужен Python 3. В папке проекта:
```
python -m http.server 8080
```
Откройте `http://localhost:8080`.
Как открыть в Telegram
Mini App работает как веб-сайт, поэтому APK для него не нужен.
Опубликуйте репозиторий через GitHub Pages.
В GitHub откройте `Settings → Pages`.
Выберите публикацию из ветки `main`, папка `/root`.
Получите HTTPS-адрес GitHub Pages.
В `@BotFather` настройте Web App / Main Mini App и укажите этот HTTPS-адрес.
Запустите приложение из своего бота.
Важно
Сейчас это frontend-прототип: история хранится локально в браузере/Telegram WebView. Для коммерческой версии можно добавить серверную базу, Telegram ID, облачную историю, оплату и админ-панель.
