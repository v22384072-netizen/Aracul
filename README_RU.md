# ОРАКУЛ — Telegram Mini App

Проект мини-приложения для колоды «Оракул» из 60 карт.

## Что уже загружено

- `index.html` — интерфейс приложения
- `styles.css` — тёмный мистический дизайн
- `app.js` — 60 карт, каталог, вытягивание карты, расклады 1/3/5 и локальная история

## Как проверить локально

Нужен Python 3. В папке проекта:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Как открыть в Telegram

Mini App работает как веб-сайт, поэтому APK для него не нужен.

1. Опубликуйте репозиторий через GitHub Pages.
2. В GitHub откройте `Settings → Pages`.
3. Выберите публикацию из ветки `main`, папка `/root`.
4. Получите HTTPS-адрес GitHub Pages.
5. В `@BotFather` настройте Web App / Main Mini App и укажите этот HTTPS-адрес.
6. Запустите приложение из своего бота.

## Важно

Сейчас это frontend-прототип: история хранится локально в браузере/Telegram WebView. Для коммерческой версии можно добавить серверную базу, Telegram ID, облачную историю, реальные изображения 60 карт, оплату и админ-панель.
